# plugin_rentals

SFRA overlay cartridge for renting pieces by the day. It provides:

- one calendar per physical unit, with cleaning days between rentals
- cart holds that are safe under concurrent checkout
- refundable deposits and size trials
- a Business Manager desk for dispatch, returns, damage inspection and refunds

Use the [repository README](../../README.md) for each feature with screenshots, and the
[installation guide](../../docs/INSTALLATION.md) to set it up.
